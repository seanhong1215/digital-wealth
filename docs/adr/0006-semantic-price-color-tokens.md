# ADR 0006 — 漲跌色使用語意 token，並解決金融介面的色彩語意衝突

**狀態**：已採納｜**日期**：2026-08-13

## 背景

**台股是紅漲綠跌，與美股相反。** 若直接在元件裡寫 `text-red-600` 表示上漲，未來要支援美股情境就得改遍所有元件。

更棘手的是，台股語意與通用 UI 慣例**直接衝突**：

| 顏色 | UI 慣例 | 台股語意 |
|---|---|---|
| 綠色 | 成功 ✓ | **下跌**（壞消息） |
| 紅色 | 錯誤 ✕ | **上漲**（好消息） |

不處理的話，下單成功彈出的綠色勾勾，在使用者的金融直覺裡是「跌」。

## 決策

### 1. 漲跌色抽為語意 token

```css
--color-price-up:   #DC2626;  /* 紅 — 台股上漲 */
--color-price-down: #15803D;  /* 綠 — 台股下跌 */
--color-price-flat: #64748B;  /* 灰 — 平盤 */
```

**命名用 `up`/`down` 而非 `red`/`green`。** 支援美股只需改 token 對應值，不動任何元件程式碼。

### 2. 狀態色刻意避開漲跌色

```css
--color-success: #5A54D6;  /* 靛藍 — 不用綠！ */
--color-error:   #BE123C;  /* 玫瑰紅 — 與漲色 #DC2626 區隔 */
--color-warning: #B45309;  /* 琥珀 */
```

### 3. 三重編碼是硬性規範

漲跌一律 **顏色 ＋ `▲▼` 符號 ＋ 正負號**，三者缺一不可。

- 紅綠色覺辨識障礙在男性約佔 8%
- 55 歲以上次要使用者對低對比顏色辨識力下降

### 4. 綠色必須調深

標準綠 `#16A34A` 對白底對比僅 **3.05:1**，未達 WCAG AA 的 4.5:1。調深至 `#15803D` 後為 **4.62:1** ✓。

### 5. 買賣不使用漲跌色

漲跌色專屬於**價格變動**。「買進」不是「跌」、「賣出」不是「漲」，混用會讓使用者誤讀。

## 替代方案

| 方案 | 捨棄理由 |
|---|---|
| 直接寫 `red`/`green` | 無法切換市場情境；語意不明 |
| 成功狀態沿用綠色 | 與台股「跌」的直覺衝突 |
| 只用顏色不加符號 | 8% 男性無法分辨 |
| 用標準綠 `#16A34A` | 對比度不合格 |

## 後果

**正面**：市場情境可切換；無障礙合格；色彩語意無衝突。這幾點都是可主動提出的面試素材。

**負面**：需維護原始層與語意層兩層 token；開發者需記住「元件不可直接用原始層」。
